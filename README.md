# 🪿 Most Wanted: Geese of the Quad

INFO 442 lab codealong: React component architecture.

## Run it

```bash
npm install
npm run dev
```

Then open the link Vite prints (usually http://localhost:5173) and edit `src/App.jsx`.

## What we'll do in lab

1. **Props** – make each `WantedPoster` show a different goose.
2. **Nested component** – pull the photo out into a `Mugshot` component and pass props two levels down.
3. **State (if time)** – add a "Spotted!" button that counts sightings with `useState`.

You don't need to push or submit anything. This is just for practice.

The finished version is on the `solution` branch: `git checkout solution`.
